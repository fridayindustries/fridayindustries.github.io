Local documents and copies

Deleting One data, unlinking One and deleting the global Friday ID are different operations. Removing a link must not erase unrelated records. A web request cannot remotely erase files on offline devices or copies you exported elsewhere. Support can explain how to remove local One data without affecting other Friday apps.

Request One-only deletion

Email fridayonedocs@gmail.com with the subject “One only — deletion request” and your @handle if known. State that Fuel, Orbit and the global Friday ID must remain intact. We must verify ownership, identify the One-specific records, and report the outcome and any justified retention. Sending an email starts a request; it is not automatic deletion or proof of completion. The operational server procedure must be validated before this page is declared complete.

Global Friday ID deletion

Global identity deletion requires a separate, explicit request and may affect other Friday apps. See the existing Friday ID deletion page. Do not send passwords, FRK2, review codes, private keys, purchase tokens or document contents to support.
