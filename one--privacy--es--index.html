Política de privacidad

26/11/2026 · os.friday.one

Responsable y contacto

Friday One - Docs & Reminders (os.friday.one). Responsable: Cristian Martinez, España. Privacidad y soporte: fridayonedocs@gmail.com.

Documentos y procesamiento local

Biblioteca, Agenda, Garaje, escaneos, planes de estudio, OCR, búsqueda y anotaciones se procesan en el dispositivo. Friday Server no almacena ni recupera documentos ni copias cifradas exportadas voluntariamente. Free invitado no requiere Friday ID ni Friday Server. El modelo OCR incluido funciona sin conexión.

Friday ID y servicios externos

Friday ID opcional gestiona identidad, perfil, dispositivos, claves públicas, sesiones y derechos propios de cada producto. No sincroniza el contenido documental. ML Kit puede enviar a Google identificadores de instalación, información de dispositivo/app y métricas de rendimiento y errores; el OCR local no significa ausencia de comunicaciones del SDK. El correo de soporte usa Gmail. GitHub Pages registra las IP de visitantes por seguridad. Esta web estática no añade analítica, fuentes remotas ni formularios.

Seguridad, conservación y derechos

Los almacenes locales y las copias exportadas usan cifrado. Conserva tu copia exportada y su contraseña: recuperar la identidad no recupera documentos perdidos. Los documentos quedan bajo tu control hasta eliminarlos. Los registros necesarios de identidad, seguridad y derechos se gestionan por separado; el responsable debe documentar sus finalidades y plazos. Puedes escribir a soporte para ejercer los derechos de privacidad aplicables. Este borrador no certifica la declaración final de Seguridad de los datos.
