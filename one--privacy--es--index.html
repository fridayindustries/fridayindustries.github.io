Política de privacidad

26/11/2026 · os.friday.one

Responsable y contacto

Friday One - Docs & Reminders (os.friday.one). Responsable: Cristian Martinez, España. Privacidad y soporte: fridayonedocs@gmail.com.

Documentos y procesamiento local

Biblioteca, Agenda, Garaje, escaneos, planes de estudio, OCR, búsqueda y anotaciones se procesan en el dispositivo. Friday Server no almacena ni recupera documentos ni copias cifradas exportadas voluntariamente. Free invitado no requiere Friday ID ni Friday Server. El modelo OCR incluido funciona sin conexión.

Friday ID y servicios externos

Friday ID opcional gestiona identidad, perfil, dispositivos, claves públicas, sesiones y derechos propios de cada producto. No sincroniza el contenido documental. ML Kit puede enviar a Google identificadores de instalación, información de dispositivo/app y métricas de rendimiento y errores; el OCR local no significa ausencia de comunicaciones del SDK. El correo de soporte usa Gmail. GitHub Pages registra las IP de visitantes por seguridad. Esta web estática no añade analítica, fuentes remotas ni formularios.

Finalidades y bases del tratamiento

Los documentos se procesan en tu dispositivo para prestar las funciones que eliges; pueden contener información personal o sensible, por lo que debes gestionar solo documentos que tengas derecho a utilizar. La autenticación, sesiones y derechos opcionales de Friday ID se tratan para prestar el servicio solicitado. La seguridad necesaria y la prevención de abuso se basan en el interés legítimo de proteger cuentas y servicio, con sujeción a los derechos aplicables. Soporte trata la información que envías voluntariamente para responder a tu solicitud y cumplir las obligaciones aplicables. Cuando se requiera consentimiento, debe ser específico para la finalidad y puede retirarse; un permiso Android no constituye consentimiento general de privacidad. Google y GitHub se rigen por sus avisos aplicables; alojar Friday Server por cuenta propia no determina dónde tratan datos esos proveedores.

Seguridad, conservación y derechos

Los almacenes locales y las copias exportadas voluntariamente usan cifrado. Conserva tu copia y su contraseña: recuperar Friday ID no recupera documentos perdidos. Los documentos locales permanecen hasta que los elimines; las copias exportadas deben gestionarse por separado. Los registros de identidad y sesión se conservan mientras sean necesarios para prestar el servicio compartido Friday ID. La prueba mínima de un derecho administrativo está separada de los documentos y se conserva mientras sustente ese derecho. Los registros de seguridad, prevención de abuso y solicitudes requieren una finalidad concreta y deben borrarse o restringirse cuando termine esa necesidad, salvo obligación legal o reclamación aplicable. No se autoriza conservación ilimitada. Puedes solicitar acceso, rectificación, supresión, limitación, oposición o portabilidad cuando proceda, y retirar el consentimiento cuando sea la base del tratamiento. Contacto: fridayonedocs@gmail.com. Puedes reclamar ante la Agencia Española de Protección de Datos u otra autoridad competente. Se responderá sin dilación indebida y, por regla general, dentro de un mes; cualquier ampliación justificada se comunicará dentro de ese plazo. Recibir la solicitud no acredita que el borrado haya terminado.
